### 🚀 ฟีเจอร์หลัก

- ✍️ **เครื่องมือจัดข้อความ** - จัดรูปแบบข้อความด้วยฟ้อนต์และรูปแบบหลากหลาย
- 🎨 **วาดภาพบนโน๊ต** - วาดรูปบนโน๊ตได้โดยตรงด้วยพู่กันหลายรูปแบบ
- 🎨 **ปรับแต่งพื้นหลัง** - เลือกสีหรืออัปโหลดภาพพื้นหลังได้
- 📱 **Responsive Design** - ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ
- 💾 **บันทึกอัตโนมัติ** - บันทึกโน๊ตอัตโนมัติขณะพิมพ์
- 🗂️ **จัดการหลายโน๊ต** - สร้างและจัดการโน๊ตหลายๆ โน๊ตได้

### 🚀 Features

- ✍️ **Rich Text Editor** - Full text formatting with multiple fonts and styles
- 🎨 **Drawing Canvas** - Draw directly on your notes with various brush styles
- 🎨 **Custom Backgrounds** - Choose colors or upload custom background images
- 📱 **Responsive Design** - Works seamlessly on desktop and mobile devices
- 💾 **Auto-Save** - Notes are automatically saved as you type
- 🗂️ **Multiple Notes** - Create and manage multiple notes with ease

### 📋 วิธีการติดตั้งและใช้งาน

#### วิธีที่ 1: ใช้งานโดยตรง
1. บันทึกไฟล์ HTML ลงในคอมพิวเตอร์
2. เปิดไฟล์ด้วยเว็บเบราว์เซอร์
3. เริ่มสร้างโน๊ตได้เลย!

#### วิธีที่ 2: ใช้ Local Web Server
```bash
# ใช้ Python
python -m http.server 8000

# ใช้ Node.js
npx http-server

# ใช้ PHP
php -S localhost:8000
```

จากนั้นเปิด `http://localhost:8000` ในเบราว์เซอร์

### 📚 คู่มือการใช้งาน

#### การสร้างโน๊ต
1. คลิก **"+ โน๊ตใหม่"** ที่แถบด้านซ้าย
2. ใส่หัวข้อในช่องด้านบน
3. เริ่มพิมพ์เนื้อหาในพื้นที่หลัก

#### การจัดรูปแบบข้อความ
- **ฟ้อนต์**: เลือกจากฟ้อนต์ในระบบ (Segoe UI, Arial, Times New Roman, ฯลฯ)
- **ขนาดตัวอักษร**: เลือกจาก 12px ถึง 32px
- **รูปแบบ**: ตัวหนา (B), ตัวเอียง (I), ขีดเส้นใต้ (U), ขีดเส้นทับ (S)

#### ฟีเจอร์การวาดภาพ
1. คลิกปุ่ม **🎨** เพื่อเข้าโหมดวาดภาพ
2. **เครื่องมือวาด** (ปรากฏในโหมดวาด):
   - 🧽 **ยางลบ**: ลบส่วนที่วาดไว้
   - 🗑️ **ล้างภาพวาด**: ลบภาพวาดทั้งหมด
   - 📝 **ล้างข้อความ**: ลบข้อความทั้งหมด
   - 🗑️ **ลบโน๊ต**: ลบโน๊ตทั้งหน้า
3. **ตัวเลือกการวาด**:
   - **เลือกสี**: เลือกสีปากกา
   - **ขนาดพู่กัน**: ความหนา 1-20px
   - **ลายเส้น**: ทึบ, ประ, จุด, ประจุด

#### การปรับแต่งพื้นหลัง
- **แถบสี**: คลิกวงกลมสีเพื่อเปลี่ยนพื้นหลัง
- **ภาพกำหนดเอง**: อัปโหลดภาพพื้นหลังของคุณเอง
- **ลบพื้นหลัง**: กลับไปใช้พื้นหลังเริ่มต้น

### 🏗️ โครงสร้างโค้ด

#### โครงสร้าง HTML
```html
<div class="toolbar">          <!-- เครื่องมือจัดรูปแบบ -->
<div class="main-container">   <!-- เลย์เอาต์หลัก -->
  <div class="sidebar">        <!-- รายการโน๊ต -->
  <div class="note-editor">    <!-- พื้นที่แก้ไข -->
    <canvas>                   <!-- ชั้นการวาด -->
    <textarea>                 <!-- เนื้อหาข้อความ -->
<div class="color-palette">    <!-- ตัวเลือกพื้นหลัง -->
```

#### ฟังก์ชัน JavaScript หลัก
```javascript
// การจัดการโน๊ต
createNewNote()     // สร้างโน๊ตใหม่
selectNote(index)   // สลับระหว่างโน๊ต
deleteNote()        // ลบโน๊ตปัจจุบัน
updateNotesList()   // รีเฟรชรายการโน๊ต

// การจัดรูปแบบข้อความ
updateTextStyle()   // ใช้การเปลี่ยนแปลงฟ้อนต์/ขนาด
toggleBold()        // เปิด/ปิดตัวหนา
toggleItalic()      // เปิด/ปิดตัวเอียง

// ระบบการวาด
toggleDrawingMode() // เข้า/ออกจากโหมดวาด
startDrawing(e)     // เริ่มการวาด
draw(e)             // วาดต่อเนื่อง
stopDrawing()       // หยุดการวาด
```

#### โครงสร้างข้อมูล
```javascript
const note = {
    id: timestamp,              // ตัวระบุเฉพาะ
    title: "หัวข้อโน๊ต",         // หัวข้อโน๊ต
    content: "เนื้อหาโน๊ต",      // เนื้อหาข้อความ
    backgroundColor: "#ffffff", // สีพื้นหลัง
    backgroundImage: null,      // ภาพพื้นหลัง (Base64)
    fontFamily: "Segoe UI",     // ฟ้อนต์
    fontSize: "16",             // ขนาดฟ้อนต์
    bold: false,               // รูปแบบตัวหนา
    italic: false,             // รูปแบบตัวเอียง
    underline: false,          // รูปแบบขีดเส้นใต้
    strikethrough: false,      // รูปแบบขีดเส้นทับ
    drawing: null,             // ข้อมูลการวาด (Base64)
    createdAt: new Date()      // เวลาที่สร้าง
}
```

### 🎯 ฟีเจอร์ทางเทคนิค

#### ระบบการวาดบน Canvas
- **หลายชั้น**: Canvas วาดทับพื้นที่ข้อความ
- **รองรับ Touch**: ใช้งานได้บนมือถือ
- **รูปแบบพู่กันหลากหลาย**: เส้นทึบ ประ จุด
- **เครื่องมือยางลบ**: ลบเนื้อหาแบบเลือกได้
- **บันทึกอัตโนมัติ**: บันทึกภาพวาดเป็น Base64

#### การออกแบบ Responsive
- **Mobile-first**: เหมาะสำหรับอุปกรณ์สัมผัส
- **เลย์เอาต์ยืดหยุ่น**: ปรับตามขนาดหน้าจอ
- **Touch Events**: รองรับการสัมผัสเต็มรูปแบบ

#### การจัดการข้อมูล
- **จัดเก็บในหน่วยความจำ**: ข้อมูลคงอยู่ในช่วงเซสชัน
- **โครงสร้าง JSON**: รูปแบบข้อมูลที่สะอาดและขยายได้
- **บันทึกอัตโนมัติ**: บันทึกการเปลี่ยนแปลงทันที

### ⚠️ ข้อจำกัด

1. **ไม่มีการจัดเก็บถาวร**: ข้อมูลหายเมื่อรีเฟรชหน้า
2. **ผู้ใช้เดียว**: ไม่มีฟีเจอร์ทำงานร่วมกัน
3. **ขึ้นอยู่กับเบราว์เซอร์**: ต้องใช้เบราว์เซอร์รุ่นใหม่
